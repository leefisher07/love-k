## 一、产品概述

**产品名称：** Love-K 红线运势平台
**产品类型：** AI驱动的情感命理分析SaaS平台
**技术栈：** Next.js 16 + React 19 + TypeScript + Prisma + PostgreSQL + DeepSeek AI
**版本：** v0.1.0

---

## 二、产品定位

Love-K 是一款结合传统命理学与现代AI技术的情感运势分析平台，为用户提供基于八字命理的深度情感分析和建议。

**目标用户：**
- 关注情感运势的年轻人（18-35岁）
- 对传统文化和命理学感兴趣的用户
- 希望获得情感指导和建议的单身或恋爱中的人群

**核心价值：**
- 传统命理学与AI技术的创新结合
- 个性化、深度化的情感分析报告
- 移动端优化的沉浸式阅读体验

## 四、功能清单

### 4.1 核心功能

#### 1. 验证码系统
- **功能描述：** 基于验证码的访问控制机制
- **验证码类型：**
  - SINGLE：单人模式验证码
  - COUPLE：双人模式验证码
- **验证码状态：**
  - ACTIVE：可用
  - EXHAUSTED：用尽
  - DISABLED：停用
- **使用次数管理：** 支持自定义最大使用次数（maxUsage）
- **使用追踪：** 记录首次使用时间、最后使用时间、已使用次数

#### 2. 单人运势分析
- **输入信息：**
  - 姓名、性别
  - 出生日期（公历/农历）
  - 出生时辰（12时辰）
  - 出生地点（省份）
  - 情感状态（普通/暗恋/暧昧/情侣/夫妻）
  - 心中所愿
  - 备注说明

- **输出报告：**
  - 八字排盘（年柱、月柱、日柱、时柱）
  - 八字总评（4字标签）
  - 2026丙午马年流年特批（400-500字深度分析）
  - 未来10年运势K线图（2026-2035）
  - 桃花旺年预测（3-5个年份）
  - 理想对象特征分析
  - 情感雷达图（6维度评分）
  - 情感锦囊建议（500-600字）

#### 3. 双人合盘分析
- **输入信息：** 两人的完整个人信息
- **输出报告：**
  - 两人各自的八字排盘和总评
  - 两人未来10年运势对比K线图
  - 两人情感雷达图对比
  - 2026丙午马年关系特批
  - 双人关系深度建议

#### 4. 历史报告管理
- **我的书简：** 查看历史生成的所有报告
- **搜索功能：** 按验证码或姓名搜索报告
- **报告详情：** 完整查看历史报告内容
- **分享功能：** 支持移动端原生分享

#### 5. 报告展示
- **沉浸式阅读体验：** 中国风设计元素
- **移动端优化：** 段落自动分隔、编号列表格式化
- **视觉化数据：** K线图、雷达图、装饰性元素
- **响应式布局：** 适配各种屏幕尺寸

# 五、业务逻辑

### 5.1 用户使用流程

```
1. 用户访问平台
   ↓
2. 输入验证码
   ↓
3. 验证码校验（类型、状态、次数）
   ↓
4. 选择模式（单人/双人）
   ↓
5. 填写个人信息
   ↓
6. 提交表单
   ↓
7. AI生成报告（单人1次调用，双人3次调用）
   ↓
8. 保存报告到数据库
   ↓
9. 扣除验证码次数
   ↓
10. 展示报告
   ↓
11. 保存到"我的书简"（localStorage + 数据库）
```

### 5.2 验证码生命周期

```
创建（ACTIVE）
   ↓
首次使用（记录 firstUsedAt）
   ↓
持续使用（更新 usageCount 和 lastUsedAt）
   ↓
用尽（usageCount >= maxUsage，状态变为 EXHAUSTED）
   或
手动停用（状态变为 DISABLED）
```

### 5.3 AI调用逻辑

#### 单人模式（1次AI调用）
```
输入：用户个人信息 + 单人模式Prompt
   ↓
AI生成：完整的单人运势报告
   ↓
数据验证：确保所有必需字段存在
   ↓
返回：完整报告数据
```

#### 双人模式（3次AI调用）
```
第1次调用：生成用户1的个人报告
   ↓
第2次调用：生成用户2的个人报告
   ↓
第3次调用：生成双人关系分析
   ↓
数据验证：确保所有字段格式正确
   ↓
合并返回：{user1, user2, horse_year_analysis, final_advice}
```

### 5.4 数据验证机制

**单人模式验证：**
- 必需字段：bazi_summary, bazi_pillars, horse_year_analysis, k_line_data, peach_blossom_years, ideal_partner, radar_scores, final_advice
- 缺失字段自动补充默认值

**双人模式验证：**
- 个人报告：bazi_summary, bazi_pillars, k_line_data, radar_scores
- 关系分析：horse_year_analysis（字符串）, final_advice（字符串）
- 对象类型自动转换为字符串（提取content字段）

### 5.5 限流机制

- **IP限流：** 每个IP每10秒最多10次请求
- **验证码限流：** 每个验证码有固定使用次数
- **失败不扣次数：** AI调用失败时不扣除验证码次数

## 六、产品亮点

### 6.1 技术亮点

1. **AI深度集成**
   - 使用DeepSeek大模型，成本低廉（单次2-3分钱）
   - 精心设计的Prompt工程，确保输出质量
   - 智能数据验证和容错机制

2. **移动端优化**
   - FormattedText组件自动格式化长文本
   - 段落自动分隔（\n\n识别）
   - 编号列表自动解析和美化
   - 响应式设计，完美适配各种屏幕

3. **性能优化**
   - Next.js 16 Turbo模式
   - 数据库索引优化
   - localStorage缓存机制
   - 并行API调用

4. **数据安全**
   - 验证码加密存储
   - 环境变量隔离
   - SQL注入防护（Prisma ORM）
   - XSS防护

### 6.2 内容亮点

1. **传统与现代结合**
   - 命理分析使用文言文和古文术语
   - 建议措施使用现代白话文
   - 严禁英语单词（AI等通用词除外）
   - 严禁夸张比喻和含蓄隐喻

2. **具体可执行的建议**
   - 明确时间："在农历三月"
   - 明确地点："去公园散步"
   - 明确行动："主动约对方见面"
   - 避免模糊表达："时机成熟时行动"

3. **深度分析**
   - 日主强弱、用神喜忌
   - 五行生克制化关系
   - 十神配置及心性特征
   - 流年刑冲合害分析
   - 具体月份建议

### 6.3 用户体验亮点

1. **中国风设计**
   - 水墨装饰元素
   - 罗盘、红线、五行图案
   - 金色边框和印章装饰
   - 古典字体和排版

2. **沉浸式阅读**
   - 全屏报告展示
   - 流畅的滚动体验
   - 清晰的信息层级
   - 视觉化数据呈现

3. **便捷的历史管理**
   - 自动保存到"我的书简"
   - 快速搜索和筛选
   - 一键分享功能
   - 离线查看支持
